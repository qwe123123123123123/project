# NEXTPLAY — персональный игровой компас

Первая рабочая версия индивидуального проекта для 10 класса. Приложение для Windows x64 и адаптивная веб-версия используют один каталог и один алгоритм рекомендаций.

## Быстрый запуск

**Windows:** распакуйте весь архив `NEXTPLAY-Windows.zip` в отдельную папку и запустите `NEXTPLAY.exe`. Не переносите один EXE отдельно от соседних файлов. Node.js, Python, Steam и установка зависимостей пользователю не нужны. Если папка `NEXTPLAY-Windows` уже лежит рядом, запускайте EXE непосредственно из неё.

**Веб-версия на Java:** для сборки на Windows нужны JDK 21 и Node.js. В корне репозитория выполните в PowerShell:

```powershell
.\java\build.ps1
java -jar build/nextplay-java.jar
```

Откройте `http://127.0.0.1:4173`. Для запуска готового JAR достаточно Java 21. Java обслуживает сайт, рассчитывает подбор и выбирает игру дня. Интерфейс работает в браузере. При работе офлайн подбор рассчитывается прямо на устройстве.

**Docker:** `docker build -t nextplay .`, затем `docker run --rm -p 4173:80 nextplay`.

**Статический предпросмотр:** `node server.cjs`. Откройте `http://127.0.0.1:4173`.

**Телефон:** откройте опубликованную веб-версию. В поддерживаемом браузере её можно добавить на главный экран. Отдельного APK или iOS-пакета в этой версии нет.

## Что уже работает

- Каталог из 1060 игр с поиском и страницами по 24 карточки. У 85 игр редакционные описания и локальные обложки, у остальных обложки из Steam.
- Персональная игра дня. При первом открытии за день появляется анкета о настроении, времени, компании и компьютере. Можно пропустить её или изменить ответы с главной. При слишком строгих настройках показывается ближайший вариант с указанием отличий. Цена и возраст остаются обязательными условиями.
- Оценка NEXTPLAY на шкале 1–100. Steam даёт 60% балла, Metacritic или PC Gamer — 40%. Карточки показывают источники, а первые 50 мест общего топа получают значок.
- Подбор по настроению, жанрам, времени сессии, компании, бесплатности, возрастной метке и слабому ПК.
- Понятные объяснения рекомендаций и индекс совпадения.
- Распознавание названий и Steam App ID, импорт выбранных файлов `appmanifest_*.acf`.
- В Windows — выбор папки Steam/steamapps и чтение манифестов установленных игр.
- Избранное, коллекция «Уже есть», имя и описание профиля, диаграмма жанров.
- Локальные отзывы с оценками, темы форума и ответы.
- Скачивание и восстановление резервной копии профиля.
- Работа основного каталога и подбора в Windows без интернета. Видео и переходы в Steam требуют интернета.

## Что пока ограничено

Данные хранятся на конкретном устройстве, а не на общем сервере. Веб-версия и Windows-приложение имеют отдельные хранилища; перенос возможен через резервную копию. Форум показывает локальные обсуждения, а не сообщения других людей. Steam OpenID/API, облачная синхронизация, распознавание скриншотов и автоматическое обнаружение всех библиотек на дисках не реализованы.

Выбор папки Steam читает только файлы манифестов в выбранной папке или её непосредственной подпапке steamapps. Другие диски нужно выбрать отдельно. Файлы не отправляются на сервер. Импорт находит игры из текущего каталога.

## Устройство исходников

| Файл | Назначение |
|---|---|
| `java/src/nextplay/RecommendationEngine.java` | Серверный подбор, объяснения, игра дня |
| `java/src/nextplay/NextplayServer.java` | Раздача сайта и API рекомендаций |
| `dist/engine.mjs` | Редакционные признаки и офлайн-подбор |
| `dist/steam-data.json` | Официальные ссылки, изображения, видео и данные Steam |
| `dist/app.mjs` | Интерфейс, профиль, импорт, отзывы и обсуждения |
| `dist/style.css` | Адаптивный дизайн |
| `desktop.cjs` | Оболочка Electron, локальный протокол и разрешённые действия |
| `preload.cjs` | Ограниченный мост для выбора папки Steam |
| `steam.cjs` | Чтение Steam-манифестов |
| `server.cjs` | Локальный сервер предпросмотра |
| `tests/engine.test.mjs` | Проверки алгоритма, каталога и Steam-импорта |

Модель личного вкуса использует до пяти ближайших примеров по жанрам и характеру игры. Примеры берутся из избранного, оценок в отзывах и кнопок «Мне нравится» и «Не мой вкус». Явные оценки подбора имеют больший вес. Карточки показывают вклад личного вкуса в процент совпадения.

Для расчёта браузер передаёт выбранные параметры, идентификаторы игр из библиотеки и выбранные оценки игр. Java-сервер вычисляет рекомендацию в памяти и возвращает результат. Профиль, тексты отзывов и содержимое файлов Steam хранятся на устройстве.

## Проверки

Запуск: `node --test tests/*.test.mjs`. Проверяются подбор, импорт, общий рейтинг, формирование запросов нового Steam API и валидация ответа.

В браузере проверены подбор, импорт, сохранение отзыва, создание темы и ответа, сохранение после перехода между страницами, воспроизведение ролика Stardew Valley и ширина 390 px без горизонтального переполнения. Проверены изображения главной страницы. Не проверено воспроизведение всех роликов на всех платформах.

Собранное приложение Electron 45.3.3 запущено в скрытом проверочном режиме: каталог загрузился, изображения доступны, мост импорта существует, Node.js не открыт веб-интерфейсу. Архив Electron проверен по официальному SHA-256. Пакет Windows не подписан сертификатом издателя.

## Сборка Windows из исходников

Приложение использует стандартный способ упаковки Electron: исходники находятся в `resources/app` официального Windows x64-дистрибутива. При обновлении копируйте `dist`, `desktop.cjs`, `preload.cjs`, `steam.cjs` и `package.json` в `resources/app`. Сохраняйте LICENSE и LICENSES.chromium.html из Electron. Для разработческого запуска можно установить Electron 45.3.3 в проект и выполнить `npm start`.

Исходники не содержат API-ключей, паролей или данных Steam-аккаунта. Доступ к сети требуется для обложек из Steam, потокового видео и внешних страниц. Обложки и видео принадлежат соответствующим правообладателям; источники перечислены в каталоге. Библиотека HLS.js распространяется по Apache-2.0; её лицензия приложена в `dist/assets/HLS-LICENSE.txt`.

Сценарий защиты, сравнение вариантов и план эксперимента — в `PROJECT.md`. Модель монетизации, предлагаемые функции подписки и условный расчёт — в `MONETIZATION.md`.

Версия 1.1: интерфейс доработан по навыку [unslop](https://github.com/heydamir/unslop) Damir Sokolovsky (CC BY 4.0). Увеличены шрифты и окно игры, убраны декоративные подписи, добавлен быстрый подбор на главной, переписано описание Stardew Valley. Подробности — в `DESIGN-CHANGES.md`. Иконки Lucide распространяются по ISC, лицензия в `dist/assets/LUCIDE-LICENSE.txt`.

### Обновление данных Steam

В папке исходников выполните `node scripts/update-catalog.mjs`. Скрипт работает последовательно, сохраняет прогресс после каждой игры, пропускает свежие оценки и прекращает запросы при 429 или HTML вместо JSON. Повторный запуск продолжает работу. При 429 не запускайте несколько копий подряд; учитывайте Retry-After сервера.

Отзывы запрашиваются через [IUserReviewsService/GetAppReviews](https://partner.steamgames.com/doc/webapi/IUserReviewsService). Старый адрес /appreviews устарел. Новый запрос использует input_json и числовые перечисления; ключ не требуется. В клиентском приложении ключей нет.

После обновления данных заново опубликуйте папку dist и скопируйте её в resources/app настольной сборки.

### Публикация на Vercel

Публикуется только содержимое dist как статический сайт. Сервер Node.js для опубликованной версии не нужен. Маршруты используют #, поэтому переадресация путей не требуется. Профиль остаётся локальным в браузере посетителя.

## Данные версии 1.3

975 игр отобраны из [Steam Games Dataset автора FronkonGames](https://huggingface.co/datasets/FronkonGames/steam-games-dataset) (MIT, DOI 10.57967/hf/0511). Дата получения снимка сохранена в `dist/bulk-catalog.json`. Оценки этих игр обновляются заменой снимка. Для свежей загрузки выполните `node scripts/fetch-catalog-snapshot.mjs --refresh`, затем `node scripts/build-bulk-catalog.mjs`. Повторный запуск без `--refresh` продолжит прерванную загрузку. Готовый снимок уже входит в сборку.

Для 85 редакционных карточек скрипт `node scripts/update-catalog.mjs --refresh` обновляет метаданные и сводки напрямую из Steam. Источник Metacritic — балл для ПК, отображаемый магазином или подтверждённый страницей самой игры. Если этот балл отсутствует, используется проверенная публикация PC Gamer. Для общего балла нужно от 100 отзывов Steam, для значка «Топ‑50» — от 1000. Тексты сторонних рецензий не копируются. В карточках размещены ссылки на оригиналы.

У карточек из снимка рекомендации оценивают общие признаки по жанрам и режимам. Фильтры по длительности, возрасту или слабому ПК пропускают характеристики, которых нет в доступных данных.
